Adds a location picker map to WooCommerce checkout and account forms.

== Description ==
WC Location Picker allows customers to select their delivery address on a map directly during checkout.  
The plugin supports saving coordinates to order meta for delivery accuracy.  

Features:
* Map picker on checkout
* Save latitude/longitude to order
* Show map in admin order page
* Works with Google Maps API or Leaflet (OpenStreetMap)

== Installation ==
1. Upload `wc-location-picker` to `/wp-content/plugins/`
2. Activate the plugin from the WordPress Plugins menu
3. Configure map settings (API key, default zoom, etc.)
